# Pastry POS 🧁

**Mobile-first point of sale for pastry businesses.**

> Product in active development. Source code and internal engineering documentation remain private.

![React Native](https://img.shields.io/badge/React_Native-20232A?logo=react&logoColor=61DAFB) ![Expo](https://img.shields.io/badge/Expo-000020?logo=expo) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white) ![Supabase](https://img.shields.io/badge/Supabase-3FCF8E?logo=supabase&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white)

Pastry POS is a mobile application for managing daily operations in small pastry businesses, including products, sales, and orders.
